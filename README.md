# 校园智能助手

这是一个包含多个实用工具的校园智能助手项目。

## 📁 项目结构

```
calculator/
├── index.html          # 计算器页面
├── campus/             # 校园智能助手
│   └── index.html      # 课表查询与食堂菜单页面
└── README.md           # 项目说明
```

## ✨ 功能特性

### 🧮 计算器
- 支持基本四则运算（加、减、乘、除）
- 百分比计算功能
- 精美的渐变背景设计
- 响应式布局，支持移动端

### 🏫 校园智能助手
- **课表查询**: 周一至周五课程表查看
- **食堂菜单**: 早餐、午餐、晚餐菜单展示
- 显示课程名称、教室信息
- 菜品价格和分类展示

## 🚀 快速开始

### 方式一：直接打开
在浏览器中直接打开 `index.html` 文件即可使用计算器。

### 方式二：本地服务
```bash
# 使用 Python 启动简单服务器
python -m http.server 8000
# 访问 http://localhost:8000
```
